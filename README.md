# terraform-jenkins-aws
# Terraform with Jenkins on AWS

This project provisions AWS infrastructure using Terraform through Jenkins CI/CD pipeline.

## Services Used

- AWS EC2
- AWS VPC
- Terraform
- Jenkins
- GitHub

## Infrastructure Created

- VPC
- Subnet
- Security Group
- EC2 Instance

## Commands

### Initialize Terraform

terraform init

### Validate

terraform validate

### Plan

terraform plan

### Apply

terraform apply

### Destroy

terraform destroy
